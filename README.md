# Coaching Hub Website

## Files
- `index.html` — the website
- `assets/coaching-hub-logo.png` — supplied Coaching Hub logo
- `assets/fortnite-street.png` — supplied Fortnite background image
- `assets/fortnite-coast.png` — supplied Fortnite background image

## How to use
1. Keep `index.html` and the `assets` folder together.
2. Open `index.html` in a browser to preview the site.
3. Upload the whole folder to your web host (for example, GitHub Pages).

## Important account note
The profile feature is a local demo. It saves a username and optional profile picture in the current browser using local storage. It does not create secure accounts, passwords, or cross-device sign-in. A real account system needs a secure backend and database.
