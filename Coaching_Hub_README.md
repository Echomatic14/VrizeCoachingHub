# Coaching Hub Website

## Main website
Open `Coaching_Hub_One_File.html` in a browser.

This is the complete, self-contained website in one HTML file. The logo and both Fortnite background images are embedded directly into the HTML, so you do not need an `assets` folder or separate image files.

## Features
- Black, gray and white design
- Coaching Hub logo and Fortnite backgrounds
- About section for VrizeFN
- Tournament coaching: £10
- Two-hour coaching session: £7
- Booking links to the Coaching Hub Discord
- Demo profile creator with username and profile-picture upload

## Discord
https://discord.gg/zEXFR9Y3F5

## Account feature note
The profile creator saves the profile in the current browser on the current device. It is a demo, not a secure account system with passwords or cross-device sign-in. A real account system requires a backend and database.

## Publishing
For GitHub Pages, upload `Coaching_Hub_One_File.html` to your repository. If you want it to open as the homepage automatically, rename it to `index.html`.
